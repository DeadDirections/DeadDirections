# Lean coverage ledger

One row per numbered theorem-level result (`thm:` / `prop:` / `cor:`) in the
built theory paper. `verification/checks/check_lean_coverage.py` enforces this
file: it checks the label set against the paper's `.aux`, checks that
every listed declaration exists in `DeadDirections/*.lean`, and regenerates
the coverage counts. Edit the rows; never hand-edit the counts.

Status values:

- `full`: the result is machine-checked at (or beyond) the paper's scope.
- `partial`: one or more clauses machine-checked; the notes name what is missing.
- `open-A`: not yet attempted; the route uses machinery the package already has.
- `open-B`: not yet attempted; needs new infrastructure (noted).
- `open-U`: not yet scoped for formalization; read the chunk before tiering.
- `out`: no formalization planned (numerical value, resolution of
  singularities, or quotient-manifold machinery Mathlib lacks).

The Scope column names, per row, the model or instance at which the
Lean declarations check the result, and what the paper's statement adds
that the declarations do not cover. A `full` row reads "at paper scope".
